# DataCleaner

Автоматизирана подготовка и обработка на данни за системи с изкуствен интелект.

Магистърска теза, *Изкуственият интелект в икономиката* — Методи Цонев.

---

## Какво прави

Подавате произволен CSV или XLSX файл. Системата:

1. **разглежда** файла — какви са колоните, какви типове данни, къде е празно;
2. **открива** какво не е наред — прикрити липсващи стойности, дубликати, аномалии,
   безполезни колони, разминаващи се изписвания на една и съща категория;
3. **планира** поправките в правилния ред и обяснява защо всяка е нужна;
4. **прилага** ги — запълва, премахва, преобразува, конструира нови признаци;
5. **показва** преди и след, и доказва с едно измерване, че данните са станали по-добри.

Всичко това през интерфейс на Streamlit, стъпка по стъпка.

## Двете папки

| Папка | Какво е |
|---|---|
| **`project/`** | кодът, данните, тестовете |
| **`writing/`** | текстовата част на български — обясненията, които влизат в дипломната работа |

Правилото: **всеки модул получава обяснението си в `writing/` в момента на написването
му.** Не после. Първата версия на проекта беше завършена като код и с нула написани
страници — този проект не повтаря това.

## Технологии

Python · **Pandas** · **NumPy** · **Streamlit**

Точно това, което заданието назовава. Всяка допълнителна библиотека за обработка на
данни е отклонение и се обосновава в `writing/decisions.md`.
